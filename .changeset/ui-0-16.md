The SDK now depends on `@hussmartinez/ui` `^0.16.0`, up from `^0.15.0`. If your application depends on ui itself, move it to `^0.16.0` too, so `npm ls @hussmartinez/ui` lists one copy: a second copy doesn't share providers with the first, so text falls back to English and announcements are lost. ui 0.16 only adds things, such as `Heading` and `HeadingLevel`; the PDF editor renders no headings, so it takes no `headingLevel`, and nothing else changes.
